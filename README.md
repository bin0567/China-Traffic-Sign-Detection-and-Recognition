# China-Traffic-Sign-Detection-and-Recognition
# 中国交通标志检测和识别系统

基于 **YOLO26n**（YOLOv8-nano）的中国交通标志检测与识别系统。使用 **CCTSDB2021** 数据集训练，对三类交通标志（指示标志、禁止标志、警告标志）进行实时检测与识别。

最终模型指标：**mAP50 = 0.968**，精确率 **0.952**，召回率 **0.930**。

## 系统架构

```
┌──────────────────────────────────────────────────────────────────┐
│                          输入图像                                │
│                     (任意尺寸, RGB)                              │
└─────────────────────────┬────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────────┐
│                      数据预处理 (LetterBox)                      │
│            等比例缩放填充至 640×640, 归一化至 [0,1]              │
└─────────────────────────┬────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────────┐
│                     Backbone: CSPDarknet                         │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌───────┐ │
│  │ Conv 3×3 │→│ C2f ×1  │→│ C2f ×2  │→│ C2f ×2  │→│  SPPF  │ │
│  │(64ch)    │  │(128ch)  │  │(256ch)  │  │(512ch)  │  │(512ch) │ │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘  └───────┘ │
│                P2 (160×160)  P3 (80×80)  P4 (40×40)  P5 (20×20)│
└─────────────────────────┬────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────────┐
│                  Neck: FPN + PAN (特征金字塔)                     │
│                                                                  │
│     P5(20×20) ── Conv ──▶ 上采样 ──▶ 拼接 ──▶ C2f ──▶ N5       │
│                                        ▲                        │
│     P4(40×40) ── Conv ──▶ 上采样 ────┘                         │
│                                        ▲                        │
│     P3(80×80) ─────────────────────────┘                        │
│                                                                  │
│     N3(80×80) ── Conv ──▶ 下采样 ──▶ 拼接 ──▶ C2f ──▶ N4       │
│     N4(40×40) ── Conv ──▶ 下采样 ──▶ 拼接 ──▶ C2f ──▶ N5       │
└─────────────────────────┬────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────────┐
│              检测头 (Decoupled Detection Head)                    │
│                                                                  │
│    80×80 特征图 ──▶ 检测头 ──▶ 小目标 (小尺寸交通标志)           │
│    40×40 特征图 ──▶ 检测头 ──▶ 中目标                           │
│    20×20 特征图 ──▶ 检测头 ──▶ 大目标                           │
│                                                                  │
│    每个检测头: 2 个卷积分支                                      │
│    ├── 分类分支: Conv(64) → Conv(64) → Conv(nc=3)              │
│    └── 回归分支: Conv(64) → Conv(64) → Conv(4×reg_max=64)      │
└─────────────────────────┬────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────────┐
│                   后处理: NMS (非极大值抑制)                       │
│             IoU 阈值=0.7, 每张图最多保留 300 个检测框             │
│        输出: 边界框坐标(xyxy) + 类别ID + 置信度                  │
└──────────────────────────────────────────────────────────────────┘
```

### 模型参数

| 组件 | 细节 |
|------|------|
| 模型名称 | YOLO26n (YOLOv8-nano) |
| 参数量 | 约 2.6M |
| FLOPs | 约 6.7 GFLOPs |
| 输入尺寸 | 640 × 640 |
| 输出尺寸 | 3 个尺度 (80×80, 40×40, 20×20) |
| 锚点 | 无锚框 (Anchor-Free) |
| 损失函数 | CIoU + DFL + 二值交叉熵 |

## 数据集

使用 **CCTSDB2021**（Chinese Traffic Sign Database 2021 版）。

### 类别定义

| 类别ID | 英文标签 | 中文名称 | 说明 |
|--------|----------|----------|------|
| 0 | `mandatory` | 指示标志 | 蓝底白图案，圆形或方形（如直行、左转、右转等） |
| 1 | `prohibitory` | 禁止标志 | 红底白图案，圆形带斜杠（如限速、禁止停车、禁止驶入等） |
| 2 | `warning` | 警告标志 | 黄底黑图案，三角形（如施工、急弯、连续下坡等） |

### 数据划分

| 数据集 | 图像数量 | 用途 |
|--------|----------|------|
| `data/train/` | **11,450 张** | 训练集 |
| `data/val/` | **4,906 张** | 验证集（训练过程中评估早停和模型选择） |
| `data/test/` | **1,500 张** | 测试集（最终评估） |
| **合计** | **17,856 张** | |

### 标注格式

YOLO 格式（归一化坐标）：

```
<class_id> <x_center> <y_center> <width> <height>
```

示例（`data/train/labels/00001.txt`）：
```
1 0.758301 0.451172 0.075195 0.175781
```
表示：禁止标志(1)，中心位于 (75.8%, 45.1%)，宽高分别占图像的 7.5% 和 17.6%。

## 快速开始

### 1. 克隆项目并安装依赖

```bash
pip install ultralytics torch torchvision matplotlib pandas pillow opencv-python
```

### 2. 训练模型

```bash
python train.py
```

训练过程将自动（参见 `train.py`）：
1. 检查 GPU 可用性并选择设备
2. 从 `yolo26n.pt` 加载预训练权重（首次运行将自动从 Ultralytics 官方仓库下载）
3. 使用 `cctsdb2021.yaml` 配置加载数据集
4. 训练 50 个 epoch，每 10 个 epoch 保存一次权重
5. 训练完成后，加载最佳模型在验证集上评估
6. 绘制训练曲线图（损失、mAP50、精确率与召回率）

### 3. 测试评估与可视化

```bash
python test.py
```

测试流程：
1. 加载 `runs/detect/train/weights/best.pt` 最佳模型
2. 在 1,500 张测试图像上评估 mAP50、精确率、召回率及各类别 AP50
3. 对测试集全部图像执行推理，每 9 张合成一张拼接可视化图

## 训练配置

### 硬件环境

| 项目 | 规格 |
|------|------|
| GPU | NVIDIA GeForce RTX 4060 |
| 显存 | 8 GB GDDR6 |
| CUDA 版本 | 12.1+ |
| 是否启用 AMP | 是（混合精度训练，减少显存占用） |

### 超参数

以下为 `train.py` 和 `args.yaml` 中的完整训练配置：

#### 基础参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `model` | `yolo26n.pt` | 使用 YOLOv8-nano 预训练权重 |
| `epochs` | 50 | 最大训练轮次 |
| `patience` | 5 | 早停等待轮次（验证 mAP50 连续 5 轮未提升则停止） |
| `batch` | 16 | 每批次图像数（受 RTX 4060 8GB 显存限制） |
| `imgsz` | 640 | 输入图像分辨率 |
| `workers` | 4 | 数据加载线程数 |
| `device` | 0 (GPU) | 使用第一张 GPU |
| `optimizer` | auto (SGD) | 自动选择优化器（实际使用 SGD） |
| `seed` | 0 | 随机种子 |
| `deterministic` | False | 不启用确定性计算（允许性能优化） |

#### 学习率与优化器

| 参数 | 值 | 说明 |
|------|-----|------|
| `lr0` | 0.01 | 初始学习率 |
| `lrf` | 0.01 | 最终学习率（为初始的 1%） |
| `momentum` | 0.937 | SGD 动量 |
| `weight_decay` | 0.0005 | 权重衰减（L2 正则化） |
| `warmup_epochs` | 5.0 | 预热轮次数（前 5 轮学习率从 0 线性升至 lr0） |
| `warmup_momentum` | 0.8 | 预热阶段的动量值 |
| `warmup_bias_lr` | 0.1 | 偏置项的预热学习率 |
| `cos_lr` | True | 使用余弦退火学习率调度 |

#### 损失权重

| 参数 | 值 | 说明 |
|------|-----|------|
| `box` | 7.5 | 边界框回归损失 (CIoU) 权重 |
| `cls` | 0.5 | 分类损失 (BCE) 权重 |
| `dfl` | 1.5 | 分布聚焦损失 (DFL) 权重 |

#### 数据增强

| 增强方式 | 参数 | 说明 |
|----------|------|------|
| `mosaic` | 1.0 | 马赛克增强（将 4 张图拼接为 1 张），epoch 30 后关闭（`close_mosaic=30`） |
| `mixup` | 0.1 | MixUp 增强概率 |
| `copy_paste` | 0.0 | 复制粘贴增强（未启用） |
| `hsv_h` | 0.015 | 色调抖动幅度 |
| `hsv_s` | 0.7 | 饱和度抖动幅度 |
| `hsv_v` | 0.4 | 明度抖动幅度 |
| `translate` | 0.1 | 平移增强比例 |
| `scale` | 0.5 | 缩放增强比例（±50%） |
| `fliplr` | 0.5 | 水平翻转概率 |
| `flipud` | 0.0 | 垂直翻转（未启用） |
| `degrees` | 0.0 | 旋转增强（未启用） |
| `shear` | 0.0 | 剪切增强（未启用） |
| `perspective` | 0.0 | 透视变换增强（未启用） |
| `auto_augment` | randaugment | RandAugment 自动增强策略 |
| `erasing` | 0.4 | 随机擦除概率 |

#### 后处理

| 参数 | 值 | 说明 |
|------|-----|------|
| `iou` | 0.7 | NMS 的 IoU 阈值 |
| `max_det` | 300 | 每张图像最多保留的检测框数 |
| `conf` | null | 训练时使用默认置信度阈值（验证时 0.001） |
| `agnostic_nms` | False | 不进行类别无关的 NMS |

#### 其他

| 参数 | 值 | 说明 |
|------|-----|------|
| `amp` | True | 混合精度训练 (FP16) |
| `cache` | False | 不缓存图像到 RAM（节省内存） |
| `save_period` | 10 | 每 10 轮保存一次权重 |
| `close_mosaic` | 30 | 第 30 轮后关闭 Mosaic 增强（使模型适应正常输入分布） |
| `pretrained` | True | 加载 ImageNet 预训练权重 |

```

 │   ├─ 每 10 轮保存权重
 │   ├─ 每轮结束后在验证集上评估

 ├─ 加载 best.pt 做最终验证评估
 └─ 绘制训练曲线 (training_curves.png)
```

### `test.py` — 测试评估与可视化脚本

#### 测试流程

```
开始
 ├─ 加载 best.pt 最佳模型
 ├─ 阶段一：定量评估（全量测试集 1500 张）
 │   ├─ 计算 mAP50, Precision, Recall
 │   └─ 计算各类别 AP50
 ├─ 释放显存，重新加载模型
 └─ 阶段二：可视化拼接图
     ├─ 随机打乱测试集 (seed=42)
     ├─ 以 batch=500 分批推理
     ├─ 每 9 张结果合成为拼接图
     └─ 共生成 167 张拼接图 → runs/detect/test_vis/
```
